Brand demonstrativ, produsele si preturile sunt exemple. Formularul nu trimite inca mesaje.

Live: https://edi09popa-art.github.io/inca-una/

HTML, CSS si JavaScript simplu, fara pas de build. Hero-ul e desenat in cod, pe canvas.
